## Publish safely
1. Open https://github.com/new
2. Create a **Public** repository named exactly `jakadwangdu`.
3. Do not initialize it with a README, license, or .gitignore.
4. Upload `README.md` to the repository root and commit.
5. Upload `.github/workflows/snake.yml` at the same path and commit.
6. Open the repository's **Actions** tab and enable workflows if prompted.
7. Run **Generate contribution snake** once using **Run workflow**.
8. Confirm the workflow succeeds and creates/updates the `output` branch.

The profile README is shown at https://github.com/jakadwangdu once the repository name exactly matches the username and the repository is public.
